# M-Alloy-CAL

A small master alloy calculator.

M-Alloy-CAL is a simple material balance calculator. It calculates the weight of master alloy needed to produce a specific alloy.

## Status

Early draft. This README is a placeholder and will be updated as the project develops.

## Planned features

- Enter the target alloy composition and batch weight
- Enter the master alloy composition
- Calculate the weight of master alloy (and base metal) required, based on a material balance
